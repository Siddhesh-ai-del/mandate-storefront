# Support

## Where to get help

- **Bug reports** — [bug report form](https://github.com/Siddhesh-ai-del/mandate-storefront/issues/new?template=bug_report.yml)
- **Feature ideas** — [feature request form](https://github.com/Siddhesh-ai-del/mandate-storefront/issues/new?template=feature_request.yml)
- **Usage questions** — [GitHub Discussions](https://github.com/Siddhesh-ai-del/mandate-storefront/discussions)
- **Security issues** — see [SECURITY.md](SECURITY.md); report privately via advisories

## Quick checks before asking

1. `npm run typecheck && npm test && npm run e2e` — do the gates pass locally?
2. Is the API running on `:3001` and the client on `:5173` (`npm run dev` starts both)?
3. Did you copy `.env.example` to `.env` if you configured optional integrations?
4. Try the in-app **Reset demo** button — it clears all server state.

## Availability

This is a pre-release project maintained in spare time. **No SLA is offered at
this stage**; issues are addressed on a best-effort basis.
